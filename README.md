# Data-Structures-Handbook-c
A comprehensive handbook of fundamental data structures and classic algorithms, covering linear lists, stacks, queues, trees, graphs, and more. Each algorithm is presented in C-style pseudocode with explanatory comments and time and space complexity analysis, serving as a practical reference for learning and review.

# 数据结构算法手册

## 项目简介

本手册是一份面向本科生的数据结构与算法学习参考资料，采用 C 风格伪代码，系统整理常见数据结构的基本操作、经典算法及其实现思路，并附有关键步骤注释与时间、空间复杂度分析。一共180页，含目录，目录可点击跳转。并附上了Latex源码。

## 内容目录

1. 顺序表
2. 链表
3. 栈
4. 队列
5. 前四个部分的经典算法思想与综合问题
6. 串
7. 数组
8. 广义表
9. 树
10. 图

## 阅读说明

- 每个算法按照函数入口、执行过程、时间复杂度与辅助空间复杂度组织。
- 关键代码配有注释，着重解释指针操作、边界条件及容易混淆的逻辑。
- 默认采用最坏情况复杂度，均摊复杂度与期望复杂度另行标注。
- 本手册使用 C 风格伪代码，旨在帮助理解算法思想，不保证所有代码均可直接编译运行。
